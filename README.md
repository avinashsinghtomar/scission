# scission
A small GPT built from scratch in PyTorch, in phases. Learning project by Avinash and Akshat.

📌 About the Project

This project aims to build a small Generative Pre-trained Transformer (GPT) model from the ground up using PyTorch.
Instead of relying on pre-built language models or high-level GPT implementations, we will explore the underlying concepts, understand how each component works, and gradually develop our own working GPT model.
The project will be divided into multiple phases, with each phase focusing on a specific part of the development process.

🎯 Project Objectives
      -Understand the fundamentals of Large Language Models (LLMs).
      -Learn the architecture and working principles of GPT.
      -Implement core Transformer components from scratch using PyTorch.
      -Understand tokenization, embeddings, attention mechanisms, and neural networks.
      -Train and experiment with our own small language model.
      -Gain practical experience with deep learning and Natural Language Processing (NLP).
